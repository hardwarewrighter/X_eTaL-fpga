librarylibs/Radix/src/Radix.xtl

Radix: an eight-digit calculator in any radix (hexadecimal, octal, decimal): the specification HEX1000's ROM program must meet Import it with an alias of your choice: "rx:" u_se< "Radix". Put libs/Radix/src on XETAL_PATH ("just path"); the reference is libs/Radix/docs. Names with l: are exported; the others are private to this file.

A number is eight digits in radix r (16, 8 or 10), as a calculator chip keeps it: a whole number from 0 to r^8 - 1. Arithmetic wraps like an odometer, modulo r^8: in hexadecimal FFFFFFFF + 1 is 0 and 5 - 7 is FFFFFFFE (the r's complement a digit-serial subtract leaves). The radix is the first argument of every function, bound once by applying the function to it: u:k_ey := rx:k_ey 16.
