1⍝# Clocked: clocked circuits as X_eTaL step functions: counters, accumulators, shift registers, a sequence detector, a RAM, and the harness that clocks them 2⍝# Import it with an alias of your choice: "ck:" u_se< "Clocked". 3⍝# Put libs/Clocked/src on XETAL_PATH ("just path"); the reference is libs/Clocked/docs. 4⍝# Names with l: are exported; the others are private to this file. 5⍝# 6⍝# A clocked circuit is state' = step(state, input) at every clock. 7⍝# Here a step is an ordinary pure dyadic function, s f̲ x: the state 8⍝# on the left, one clock's input on the right, the next state out. That 9⍝# function is what becomes hardware: registers for the state, the 10⍝# function as the logic between them. The harness, r_un and t_race, 11⍝# applies it once per input, as a clock would: a loop, p_ower over a 12⍝# tuple of the clock count and the state (X_eTaL has no left fold yet, 13⍝# ask F5). It is the testbench, never lowered. Numbers are 8-bit two's complement (Fixed). 14ᶠˣ⁼u̲se< "Fixed" 15 16⍝## The harness: one input per clock 17 18⍝# s0 'step r_un xs: the state after every input (an item, or a row of 19⍝# a matrix, per clock). 20⍝# >> "ck:" u_se< "Clocked" 21⍝# >> 0 'ck:a_ccumulate ck:r_un 1 2 3 4 22⍝# 10 23ˡr̲un ← { f̲ s xs → 24 (n, last) ← (t̲ally xs) '{ (i, t) → (i + 1, t f̲ i s̲elect xs) } p̲ower (1, s) 25 last 26} 27 28⍝# s0 'step t_race xs: every state from s0 on, one per row (a vector 29⍝# for a scalar state): what the registers hold after reset and after 30⍝# each clock. 31⍝# >> "ck:" u_se< "Clocked" 32⍝# >> (0 0 0) 'ck:s_hift ck:t_race 1 1 0 33⍝# 0 0 0 34⍝# 0 0 1 35⍝# 0 1 1 36⍝# 1 1 0 37ˡt̲race ← { f̲ s xs → 38 first ← (1 c̲at s̲hape s) r̲eshape s 39 (n, last, rows) ← (t̲ally xs) '{ (i, t, m) → t1 ← t f̲ i s̲elect xs◆ (i + 1, t1, m c̲at t1) } p̲ower (1, s, first) 40 rows 41} 42 43⍝## Counters and accumulators 44 45⍝# s t_ick e: an 8-bit counter that counts when its enable e is 1. 46⍝# >> "ck:" u_se< "Clocked" 47⍝# >> 127 ck:t_ick 1 48⍝# -128 49ˡt̲ick ← { s e → 8 ᶠˣw̲rap s + e } 50 51⍝# s a_ccumulate x: an 8-bit accumulator (an adder and a register). 52⍝# >> "ck:" u_se< "Clocked" 53⍝# >> 100 ck:a_ccumulate 100 54⍝# -56 55ˡa̲ccumulate ← { s x → 8 ᶠˣw̲rap s + x } 56 57⍝## Shift register 58 59⍝# s s_hift b: the bits move one place toward the front and b comes in 60⍝# at the end (a serial-in, parallel-out shift register: wiring and 61⍝# flip-flops, no logic). 62⍝# >> "ck:" u_se< "Clocked" 63⍝# >> (0 0 0 1) ck:s_hift 1 64⍝# 0 0 1 1 65ˡs̲hift ← { s b → (1 d̲rop s) c̲at b } 66 67⍝## A sequence detector: a state machine from a table 68 69⍝# Next101: the next state of a detector of the bits 1 0 1 (overlapping), 70⍝# a table indexed by state and bit: item 1 + s + 4 * b.
