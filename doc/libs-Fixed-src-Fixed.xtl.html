librarylibs/Fixed/src/Fixed.xtl

Fixed: fixed-width two's complement numbers at a stated width, the arithmetic a w-bit circuit does Import it with an alias of your choice: "fx:" u_se< "Fixed". Put libs/Fixed/src on XETAL_PATH ("just path"); the reference is libs/Fixed/docs. Names with l: are exported; the others are private to this file.

X_eTaL's Int is 64 bits wide; hardware is 8, 16 or 32. Until X_eTaL has sized integer types (ask F3 in docs/xetal-asks.md), the width is written in the program: 16 ᶠˣw̲rap x + y is what a 16-bit adder gives, and the evaluator computes exactly that, so it is the reference the circuit must match bit for bit. Every function takes the width first (one number) and works on whole arrays of any shape. A function of three arguments is used curried: bind the width once, ᵘa̲dd ← ᶠˣa̲dd 16, then x ᵘa̲dd y.
