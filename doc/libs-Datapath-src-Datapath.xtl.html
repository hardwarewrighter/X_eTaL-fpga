ˡs̲um : Int -> Int -> Int

function · line 67

w s_um x: the sum of a vector as a balanced tree of w-bit adders: the first half added to the second half, item by item, then that vector likewise, down to one number (a loop over the log2 n levels of the tree; an odd length is padded with a 0). Wrapping at every adder gives the same bits as wrapping the exact sum once (checked in tests/checks.xtl).
