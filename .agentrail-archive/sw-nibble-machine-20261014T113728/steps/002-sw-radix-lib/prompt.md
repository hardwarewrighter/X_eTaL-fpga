The reference for the calculator: a pure X_eTaL library of digit-serial arithmetic in a radix (16 first, then 8 and 10): numbers as digit vectors of a fixed length (the display's), add, subtract, multiply (and divide if decided), overflow as the machine will report it, and the key-sequence semantics of the calculator (digits, operators, equals, clear) as a step over a display state, so the machine's ROM program has an exact specification.
