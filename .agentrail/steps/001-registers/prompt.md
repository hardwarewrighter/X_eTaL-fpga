State in the provisional IR and in circuits. XIR: a state value with its initial value (state %s : i16[5] = 0 0 0 0 0), the next-state binding (next %s = %t), an input stream (stream %k : i8 = 1 2 10 3 4 14, one item per clock), lookup (a constant table indexed by a value), rom (a constant table, the 4-bit machine's program store) and ram (a small read-write memory with an address, write enable and data, the machine's 64 by 4-bit RAM); the interpreter runs the step once per stream item and outputs the final state (and, with a trace flag, every state). components/rtl: registers for the state, the next-state logic combinational, the stream fed one item per clock, memories as Verilog arrays (inferable as block RAM by Yosys), done when the stream ends; the simulator; Verilog. Tests: a counter, an accumulator, a shift register, a small state machine, a RAM written then read; a twin of Fixed's counter demo (16-bit counter ticks from 65530). check-equiv and check-rtl cover them.
