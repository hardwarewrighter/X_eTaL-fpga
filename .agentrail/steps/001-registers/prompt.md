State in the provisional IR and in circuits. XIR: a state value with its initial value (state %s : i16[5] = 0 0 0 0 0), the next-state binding (next %s = %t), an input stream (stream %k : i8 = 1 2 10 3 4 14, one item per clock), lookup (a constant table indexed by a value) and rom; the interpreter runs the step once per stream item and outputs the final state (and, with a trace flag, every state, as calc:t_race does). components/rtl: registers for the state, the next-state logic combinational, a stream fed one item per clock from a ROM in the testbench schedule, done when the stream ends; the simulator; Verilog (the state registers in the one always block). Tests: a counter, an accumulator, a shift register, a small state machine; a twin for Fixed's counter demo (16 ticks of a 16-bit counter from 65530). check-equiv and check-rtl cover them.
